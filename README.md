# Happy Place Website

Kostenlose statische Marken- und Produktwebsite für `happyplace.com.de`.

## Veröffentlichung

Die Website ist für GitHub Pages vorbereitet. Der Verkauf bleibt zunächst bei Etsy, daher sind keine Zahlungs- oder Kundendaten auf der Website erforderlich.

Impressum und Datenschutz wurden mit den hinterlegten Domain-Kontaktdaten ergänzt.
